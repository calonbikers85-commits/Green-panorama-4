# 🏡 Green Panorama 4 v1.0.6

Aplikasi informasi dan komunikasi digital khusus untuk warga Komplek **Green Panorama 4**. Proyek ini dikembangkan menggunakan **Capacitor** dan di-build secara otomatis menjadi file Android APK menggunakan **GitHub Actions**.

---

## 🚀 Pembaruan Terbaru (Update v1.0.6)
* **Penyusunan Struktur Web Inti**: Berhasil membuat folder penyimpanan awal `/www` dan file utama `index.html` langsung dari HP.
* **Perbaikan Otomasi Android SDK**: Integrasi lisensi internal dan pelacakan direktori otomatis yang stabil pada sistem GitHub Actions (`blank.yml`).
* **Pemberian Pengaman Jalur Kode**: Penambahan fungsi bypass sintaksis instalasi NPM untuk mencegah kegagalan build selama masa pengembangan awal.

* 📢 **Informasi & Pengumuman**: Komunikasi satu pintu dari pengurus komplek untuk seluruh warga.

---

## 🛠️ Panduan Pengembangan Awal (Lewat HP / Laptop)

Aplikasi ini menggunakan folder utama `/www` sebagai base layout web. Jika Anda ingin melakukan pembaruan kode aplikasi:
1. Perbarui kode HTML/CSS/JS Anda di dalam file `www/index.html`.
2. Pastikan file `package.json` menyertakan dependensi Capacitor yang sesuai di folder root.

---

## 📥 Cara Mengunduh & Membagikan APK Warga
1. Masuk ke halaman utama repositori ini di GitHub.
2. Di kolom sebelah kanan, cari menu **Releases** dan ketuk rilis terbaru (**v1.0.6**).
3. Gulir layar ke bagian paling bawah, lalu ketuk menu **Assets**.
4. Klik file **`app-debug.apk`** untuk mengunduhnya langsung ke HP Anda.
5. File APK mentah ini siap diinstal atau dibagikan ke WhatsApp Group warga komplek!
